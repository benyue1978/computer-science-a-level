# First memory activity — parent trial

This is a trial guide, not evidence that a trial has happened. The first real parent/child session is pending.

Run the built app locally and start at the home page. Allow the learner to explain in either English or Mandarin. Use the parent guide when needed; do not treat completion of the pages as proof of understanding.

1. Can the learner distinguish the outside label (address) from the value inside a cell?
2. Can they find address 11, then say what is stored there without answering 11?
3. Before revealing a read, ask whether the value will disappear. After reading, ask what changed in the interface and what stayed unchanged in memory.
4. Ask where the value 7 is stored. Note whether they answer an address or repeat the value.
5. Before replacing the contents at 11, ask what will change. Afterwards, ask why the address and the other cells stayed unchanged.
6. Use the new example without hints. Check contents at 21, the address holding 3, and whether both 20 and 22 can hold 8.
7. At the next session, draw three new address/value pairs and ask one “where” and one “what” question.

Record the stage, the learner's actual words, any hint needed, and any interface confusion. Avoid a score or pass/fail label. If a concept needs developer explanation, revise this bite before adding registers or buses.
