从零开始：怎样使用这套题库

你不需要先做完一整份试卷。从一个知识点、一个术语、一道小问开始。

第一次使用

1. 先进入 P1，点“从基础开始”或“背诵与记忆”。

2. 展开“中文导学”，不认识的概念先看中英记忆卡，再打开本章完整导学。

3. 阅读英文原题；如果有“公共资料”，先看其中的背景、图或表。

4. 在作答框独立写答案。开始时可以中文整理思路，再尝试用英文表达。

5. 点击“查看答案与讲解”，读中文解题说明，再按官方评分标准逐点核对。

6. 标记“需要复习”或“已经掌握”。隔一段时间从“待复习”重新尝试，不能仅因答案看着熟就标掌握。

学习记录保存在当前浏览器，不会上传。换浏览器/设备或清除数据前，用“导出学习记录”备份，再用“导入记录”恢复。不同浏览器对直接打开本地文件的存储支持不同；若有保存提示，请及时导出。

不同问法要写到什么程度

指令词怎么回答
State / Give / Identify直接写所要求事实/名称，注意要几个
Define给出准确含义与必要限定，不能只重复术语
Describe说明特征，或按顺序写过程
Explain写出原因、机制和结果之间的联系
Compare围绕相同维度对照两者，不只单独介绍一个
Justify结合题目条件给出选择理由
Calculate / Convert写公式/步骤、代入数值与单位或位数
Complete / Draw / Write真正补全表格、画图或写出算法，不只描述你会怎么做

分值能提示需要多少独立内容，但不总是“一句话一分”。实际以该题评分标准为准。代码题可能按功能、语法、测试证据分别评分。

四种主要学习方式

  • 记忆 Memory：记清定义、名称、用途，能用英文准确说出。
  • 步骤 Procedure：会重复执行转换、计算、追踪等过程；只背最终数值没有帮助。
  • 理解 Understanding：能用自己的话解释原理及因果，再用英文组织答案。
  • 应用 Application / 编程 Implementation：读出场景条件，选用知识点并真正构造答案或程序。

难度1–4是学习负担估计，不是实际考生得分率；也不保证同一类型每道都简单。每题可以涉及多个知识点。主考点用于统计，其余标签帮助交叉学习。

建议的学习顺序

P1 基础理论：信息表示 → 硬件与处理器 → 系统软件 → 网络与安全 → 伦理 → 数据库。可以按学校进度改变顺序。

P2 书面算法：变量/类型 → 条件/循环 → 数组/记录/文本文件 → 子程序 → 测试和开发。每次学完都手写并追踪，不要只读代码。

P3 进阶理论：先复习对应AS基础，再学浮点、协议、布尔代数、系统管理、加密、AI和ADT等主题。

P4 上机编程：选学校使用的Python、Java或Visual Basic控制台环境，先运行基础例子，再实现数组、子程序、ADT、递归、OOP、文件和异常处理。本站作答框只保存文字，不运行或自动判分代码；要在自己电脑的编程环境实际运行，并对照题目测试要求保存证据。

怎样判断自己已经会了

  • 遮住记忆卡，能同时说出英文术语和中文含义。
  • 换一道数值或场景不同的题，仍能解释为什么这样做。
  • 对照评分标准，能指出自己每一句/每段代码拿哪个得分点。
  • 做错时能分辨：概念没学会、英文没读懂、计算失误、漏场景，还是答案表达太模糊。

如果做不到其中一项，先标“需要复习”，回到该知识点导学，再做同类题。
