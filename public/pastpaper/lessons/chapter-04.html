04 处理器基础 Processor Fundamentals

中文知识点提要 · Cambridge 9618 · 2027–2029 考纲

4.1 CPU Architecture

练习本知识点 →

Von Neumann 架构的 stored program concept：指令和数据存储在同一主存地址空间，CPU 从内存读取指令执行。IAS（Immediate Access Store）是可直接访问的主存概念，不是辅助存储。

部件/寄存器职责
ALU算术、逻辑、比较与移位
CU译码指令，发控制信号协调执行
System clock提供同步节拍；一条指令可能需要多个时钟周期
PC下一条待取指令的地址
MAR本次要读/写的内存地址，可对应指令或数据
MDR在 CPU 与内存之间传输的指令或数据
CIR当前正在译码/执行的指令
ACC运算操作数/中间结果；本考纲简化指令集中的通用寄存器
IX变址寻址的偏移
Status registerzero、carry、overflow、interrupt 等标志

General-purpose register 可保存多种运算数据；special-purpose register 有特定作用。

Address bus 携带地址，简化模型下从 CPU 指向主存/I/O；data bus 双向携带数据/指令；control bus 含读写、中断等信号，方向视信号而定。n-bit 地址总线能区分 2ⁿ 个地址；只有题目说每地址一个 byte 时才对应 2ⁿ B。

Fetch–decode–execute

以下采用 M[address] 表示内存内容，避免双重括号歧义：

MAR ← PC
MDR ← M[MAR]       // CU 发出 read，内容经数据总线传回
PC  ← PC + 1       // 简化模型按一个地址单位递增
CIR ← MDR
// CU 译码 opcode 与 operand；取操作数；执行并保存结果

跳转可改写 PC，所以执行顺序不一定一直递增。寄存器间的内部复制不应全部说成经过外部地址总线。

中断 interrupt使 CPU 响应 I/O、时钟、硬件故障或软件异常。简化模型在当前指令结束时检查可响应中断 → 根据优先级/屏蔽状态决定处理 → 保存 PC 和寄存器等上下文 → 执行 ISR → 恢复并继续。不是每次中断都丢弃当前任务。

性能与接口

  • 更高 clock frequency 通常可更快完成节拍，但还受每指令周期、架构、散热影响。
  • 多核能并行执行可分配的任务，不会令所有程序按核数等比例加速。
  • 更宽 data bus 每次传更多位；更宽 address bus 增大可寻址空间，含义不同。
  • Cache 保存常用/近期指令与数据，命中时减少等待主存；容量增加的效果受访问模式影响。
  • USB：通用串行外设连接、设备识别与驱动支持；HDMI：数字音视频；VGA：模拟视频，通常不含音频。

4.2 Assembly Language

练习本知识点 →

汇编以 mnemonic 和地址/标签表达机器指令；assembler 转成 machine code。两遍汇编：第一遍分配地址、建立 label→address 符号表；第二遍解析标签并生成机器码，可处理 forward reference。

寻址取值方式示例
Immediate操作数就是数值LDM #5 → ACC=5
Direct操作数给数据地址LDD 100 → ACC=M[100]
Indirect先到给定地址取真正地址LDI 100 → ACC=M[M[100]]
Indexed基址加 IXLDX 100 → ACC=M[100+IX]
Relative相对于 PC 的位移目标=题目规定的 PC 基准+offset

常用指令：LDR #n 设 IX；MOV IX 将 ACC 复制到 IX；STO a 写内存；ADD/SUB 算术；INC/DEC 增减；CMP/CMI 比较；JMP 无条件跳转；JPE/JPN 根据比较真/假跳转；IN/OUT 输入字符编码/按编码输出字符；END 结束。JPN 不能望文生义当成 jump-if-negative，必须按题目指令表解释。

LDM #6
ADD #4
STO 200
END

结果 ACC=10、M[200]=10。Tracing 应逐行记录 PC、ACC、IX、被修改的内存及输出；OUT 的 65 可能是字符 A，不能自动写成十进制文本 65。

4.3 Bit manipulation

练习本知识点 →

  • Logical shift 空位补 0；arithmetic right shift 复制符号位，保留补码符号；cyclic shift 把移出的位放回另一端。
  • 算术左移通常左移补 0，但必须检查符号与溢出；“左移就是乘 2”只有结果可表示时才成立。负数右移与整数除法舍入规则需按题目定义。
  • 掩码 mask：X AND mask 测试/保留位；X OR mask 置 1；X AND (NOT mask) 清 0；X XOR mask 翻转。
  • 例（bit 0 为最低位）：X=10100100，测试 bit 2：AND 00000100 非零；设置 bit 1：OR 00000010 → 10100110；清 bit 5：AND 11011111 → 10000100。

自测与易错点

1. 若 M[100]=200、M[200]=7、IX=3、M[103]=9，三种加载结果：LDD 100→200，LDI 100→7，LDX 100→9。

2. 解释中断中为什么需要保存 PC；完整写出取指寄存器传送过程。

3. 用位操作控制一组灯时，说明其他灯为何不受影响。
