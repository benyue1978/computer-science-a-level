10.1 Data Types and Records

练习本知识点 →

INTEGER 存整数；REAL 存可有小数的数据；CHAR 单个字符；STRING 字符串；BOOLEAN 真/假；DATE 日期。电话号码、含前导零的学号一般选 STRING，不用于算术的数字外观不代表必须用 INTEGER。

Record 将不同类型的相关字段放在一个标识符下：

TYPE StudentRecord
    DECLARE ID : STRING
    DECLARE Mark : INTEGER
ENDTYPE
DECLARE Student : StudentRecord
Student.ID ← "0012"
Student.Mark ← 84
OUTPUT Student.ID, Student.Mark

Record 是一个对象的不同属性；array 是同类型元素的有序集合。

10.2 Arrays

练习本知识点 →

数组使用 index 定位；lower/upper bound 均包含时，元素个数为 upper−lower+1。二维数组适合成绩矩阵/棋盘，需分别遍历行列。

DECLARE Marks : ARRAY[1:30] OF INTEGER
DECLARE Grid : ARRAY[1:3, 1:4] OF INTEGER
FOR Row ← 1 TO 3
    FOR Col ← 1 TO 4
        Grid[Row, Col] ← 0
    NEXT Col
NEXT Row

Linear search 线性查找

Position ← 0
Index ← 1
WHILE Index <= N AND Position = 0 DO
    IF Marks[Index] = Target THEN
        Position ← Index
    ENDIF
    Index ← Index + 1
ENDWHILE

找到返回第一处位置；0 代表没找到（本例索引从 1 开始）。循环体只在 Index 合法时访问数组，不依赖越界表达式的短路求值。数组无需预先排序。

Bubble sort 冒泡排序（升序）

Limit ← N
REPEAT
    Swapped ← FALSE
    FOR Index ← 1 TO Limit - 1
        IF Marks[Index] > Marks[Index + 1] THEN
            Temp ← Marks[Index]
            Marks[Index] ← Marks[Index + 1]
            Marks[Index + 1] ← Temp
            Swapped ← TRUE
        ENDIF
    NEXT Index
    Limit ← Limit - 1
UNTIL Swapped = FALSE OR Limit <= 1

适用 N≥2；N<2 时无需排序。每一轮把未排序部分最大项推到右端；无交换即可提前结束。例 [5,1,4] 第一轮成为 [1,4,5]。交换必须暂存旧值。

10.3 Files

练习本知识点 →

文件用于断电后保留数据、处理超出内存的数据、与其他程序共享输入输出。文本文件按行读取：

DECLARE Line : STRING
OPENFILE "marks.txt" FOR READ
WHILE NOT EOF("marks.txt") DO
    READFILE "marks.txt", Line
    OUTPUT Line
ENDWHILE
CLOSEFILE "marks.txt"

OPENFILE "log.txt" FOR APPEND
WRITEFILE "log.txt", "Finished"
CLOSEFILE "log.txt"

READ 读；WRITE 新建/覆盖；APPEND 在末尾追加。要能处理空文件、末行、数据转换与关闭文件。READFILE 读出的文本不会自动成为正确范围内的整数。

10.4 Introduction to ADT

练习本知识点 →

ADT = 一组数据及其合法操作的抽象定义，使用者关注操作语义，实现者决定存储方式。

ADT顺序与操作典型应用/数组实现
Stack 栈LIFO；push/pop/peek撤销、调用栈；数组+top
Queue 队列FIFO；enqueue/dequeue打印任务；数组+front/rear，可循环使用
Linked list 链表节点包含 data 与 next，沿链接访问动态逻辑顺序；数据数组+next 数组或记录数组

插入/删除链表时改变链接，不必移动所有后续数据。链表在数组中实现仍受物理容量限制，需追踪 start pointer 与 free list。AS 要会描述、手工添加/修改/删除及数组实现思路；考纲明确本节不要求编写这些 ADT 的伪代码，A2 第 19 章会要求。

自测与易错点

1. [3:12] 有几个元素？答：10。

2. 顺序 push A、push B、pop，输出 B；enqueue A、enqueue B、dequeue，输出 A。

3. 用 [9,3,7,1] 逐轮追踪冒泡排序，分清“一次比较”和“一轮扫描”。
