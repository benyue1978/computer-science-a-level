03 硬件 Hardware

中文知识点提要 · Cambridge 9618 · 2027–2029 考纲

3.1 Computers and their components

练习本知识点 →

输入设备获取数据，输出设备呈现结果，primary memory 保存当前执行所需内容，secondary storage 长期保存程序和数据；removable storage 便于携带、转移和离线备份。

Embedded system 嵌入式系统为较大设备中的特定功能而设计，包含处理器、存储和 I/O，例如洗衣机控制器。可采用固件、实时操作系统或其他 OS；不能断言它没有操作系统。优势是针对任务优化、体积和功耗可较小；限制是升级、维修与通用性。

HDD 通常单位容量成本低但有机械延迟；SSD 随机访问快、抗震、安静，但价格和耐写性需考虑。光盘适于分发/归档，容量、速度和兼容性有局限。

Buffer 缓冲区暂存待传数据，协调 CPU 与外设、网络或流媒体的速度差。生产者填充，消费者取出；需处理满/空状态，可配合中断通知。Buffer 不是永久存储，也不同于用于重复访问加速的 cache。

主存比较

类型数据保持/原理典型用途
RAM断电丢失，可读写活跃程序、数据、栈与缓冲区
ROM 类存储非易失，正常使用以读取为主启动代码、固件
SRAM双稳态电路保存位，不需周期刷新；快、贵、密度较低cache
DRAM电容存电荷，需刷新；密度高、单位成本较低主内存
PROM一次性编程固定固件
EPROM紫外线擦除后重新编程，通常整片擦除较旧的可更新固件
EEPROM电擦除并重新编程，可在电路中更新配置/固件

SRAM 与 DRAM 都是易失的；“不刷新”不等于断电保留。讨论功耗时要结合容量、工作状态，避免绝对判断。

Monitoring 与 control

Monitoring 采集、记录、显示或报警；control 根据测量与目标的差异自动驱动 actuator 改变系统。温控例：温度传感器 → 必要时 ADC → 处理器比较设定值 → 控制加热器 → 温度改变后再次测量。Feedback 是将输出造成的结果反馈到后续输入，用于持续调整。温度、压力、红外、声音传感器应按场景选；actuator 可为电机、阀门、继电器等。

3.2 Logic Gates and Logic Circuits

练习本知识点 →

NOT 为输入取反。其余考纲基本门为两输入：

ABANDORNANDNORXOR
0000110
0101101
1001101
1111000

AND 全真才真；OR 至少一真；NAND 是 AND 取反；NOR 是 OR 取反；XOR 恰好一个输入为真。必须认识并手绘官方标准门符号。

从表达式画电路：按括号和运算顺序给中间结果命名，逐门连接。从电路/表达式填真值表：n 个输入列出 2ⁿ 行，再计算中间列。由真值表写式：对输出为 1 的每一行写 minterm（输入 0 则取反），再 OR 合并。例如仅 A=0,B=1 或 A=1,B=0 时报警：Q=(NOT A AND B) OR (A AND NOT B)。

自测与易错点

1. 说明为什么 cache 用 SRAM，而主存多用 DRAM。

2. 完整画出 Q = (A OR B) AND NOT C 的电路并列八行真值表。

3. 用“感测 → 比较 → 执行 → 再感测”解释控制过程，不把传感器与执行器互换。
