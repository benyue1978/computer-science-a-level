11.1 Programming Basics

练习本知识点 →

声明 type 与 identifier；initialisation 在第一次使用前赋初值；assignment 以 ← 改变值，条件比较使用 =。常量有固定值，变量可变化。

CONSTANT MaxSize = 100
DECLARE Count : INTEGER
DECLARE Total : REAL
Count ← 0
Total ← 0.0
INPUT Count
OUTPUT "Count: ", Count

算术运算：+ - * / DIV MOD ^。例如 17 DIV 5 = 3、17 MOD 5 = 2；/ 与整数商不同。关系运算 = <> < <= > >=；逻辑运算 AND OR NOT。使用括号明确优先级。

Built-in function 返回一个值；library routine 提供已实现的处理。会依据给定函数说明选择参数、理解返回值。字符串函数按题目提供的定义使用，不假定索引从 0 开始，也不必死记某语言的函数名。

IF Score >= 80 THEN

    ELSE

CASE OF Choice
    1 : OUTPUT "Add"

    OTHERWISE : OUTPUT "Invalid"
ENDCASE
循环何时检查适用场景
FOR ... TO ... NEXT预设计数范围已知处理 N 项
WHILE ... DO ... ENDWHILE执行前，可能零次文件读取、条件可能起初不满足
REPEAT ... UNTIL执行后，至少一次；条件真时停止菜单、至少输入一次的验证
REPEAT
    INPUT Age
UNTIL Age >= 0 AND Age <= 120

相同条件若用于 WHILE，要仔细决定条件代表“继续”还是“结束”。循环变量/条件状态必须变化。

11.3 Structured Programming

练习本知识点 →

Procedure 完成一项操作，通过 CALL 调用；function 通过 RETURN 返回值并可用在表达式中。拆分模块提高可读性、复用和独立测试能力。

FUNCTION Square(BYVAL X : INTEGER) RETURNS INTEGER
    RETURN X * X
ENDFUNCTION

PROCEDURE AddOne(BYREF X : INTEGER)
    X ← X + 1
ENDPROCEDURE

DECLARE Number : INTEGER
Number ← 4
OUTPUT Square(Number)
CALL AddOne(Number)
OUTPUT Number

输出 16、5。BYVAL 复制参数值，修改局部形参不改变调用者变量；BYREF 关联调用者存储位置，可修改原值。

  • Parameter 形参是定义中的 X；argument 实参是调用时的 Number。
  • Header 给出名称、参数及返回类型；interface 说明模块接收什么、返回/修改什么。
  • Local variable 属于子程序作用域，global variable 可被多个模块访问；尽量通过参数传值减少隐藏依赖。
  • 返回值与 OUTPUT 不相同：前者交还调用者用于进一步计算，后者向外显示。
  • Efficient pseudocode 先保证正确，再避免不必要的重复运算/遍历；不因追求短而使逻辑含糊。

自测与易错点

1. 把 AddOne 的 BYREF 改成 BYVAL 后，最后输出为 4；解释原因。

2. 独立写出输入 10 个数、累计正数并计算其平均值的程序，考虑没有正数。

3. 选择循环必须解释“是否已知次数、是否允许零次、何时终止”。
