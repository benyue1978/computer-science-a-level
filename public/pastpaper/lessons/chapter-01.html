1.1 Data Representation 数据表示

练习本知识点 →

单位与进制

  • bit 是一位二进制；byte = 8 bits；nibble = 4 bits。传输速率通常用 bit/s，文件大小通常用 byte。
  • 十进制前缀：kB = 10³ B，MB = 10⁶ B，GB = 10⁹ B，TB = 10¹² B。
  • 二进制前缀：KiB = 2¹⁰ B，MiB = 2²⁰ B，GiB = 2³⁰ B，TiB = 2⁴⁰ B。题目给定单位优先，不把 MB 自动当作 MiB。
  • 二进制位权从右到左为 1、2、4、8……；十六进制每位对应 4 bits，A–F 代表 10–15。
  • 十进制整数转二进制：连续除以 2，余数逆序排列；二进制转十进制：位权相加。例：10110110₂ = B6₁₆ = 182₁₀。
  • BCD（Binary Coded Decimal）每个十进制数位独立编码为 4 bits：59 → 0101 1001，不同于普通二进制 0011 1011。1010–1111 不是有效的单个 BCD 数位。
  • BCD 适合十进制显示、需要十进制精确表示的计算；代价是占用位数较多。十六进制用于阅读地址、机器码、RGB 颜色和 IPv6，计算机内部仍保存二进制。

有符号整数与运算

表示法（n bits）范围特征
无符号 unsigned0 到 2ⁿ−1所有位都是非负位权
反码 one's complement−(2ⁿ⁻¹−1) 到 +(2ⁿ⁻¹−1)负数由正数逐位取反；有正零和负零
补码 two's complement−2ⁿ⁻¹ 到 2ⁿ⁻¹−1最高位权是 −2ⁿ⁻¹；只有一个零

8-bit 的 +13 是 00001101，−13 的反码是 11110010，补码是 11110011。补码转十进制可以直接用负的最高位权：11110011 = −128+64+32+16+2+1 = −13。

二进制加法遵循 1+1=10、1+1+1=11。减法可转换为加上减数的补码，并保留指定位宽。8-bit 7−10 = 00000111+11110110 = 11111101 = −3。

Overflow 溢出表示真实结果超出可表示范围。补码加法中，同号相加却得到异号结果就是溢出：01111111+00000001=10000000，不能解释成正确的 128。最高位有进位不等于有符号溢出。

字符编码

Character set 为字符指定数值编码。ASCII 基础字符集为 7 bits（128 个编码）；extended ASCII 通常为 8 bits，但有不同代码页。Unicode 提供更大的统一字符空间；Unicode 不等于“每个字符固定 16 bits”，UTF-8 等编码的长度可以变化。不需背诵具体 ASCII 码，但要会读题目给出的编码表。

1.2 Multimedia 多媒体

练习本知识点 →

Bitmap 位图是像素 pixel 的网格；每个像素由 colour depth/bit depth 指定颜色编码。b bits 能表示最多 2ᵇ 种颜色。文件头 header 保存尺寸、位深等元数据。

未压缩图像数据字节数 = 宽 × 高 × 每像素位数 ÷ 8。例如 800×600、24-bit：1,440,000 B = 1.44 MB；文件头另计。分辨率提升增加像素数，位深提升增加可表示颜色，都会增大体积。屏幕分辨率与图像像素尺寸是不同概念。

Vector 矢量图保存 drawing list：对象（线、圆、多边形等）及其坐标、大小、颜色、填充等 properties。适合可缩放的图标、工程图；位图适合照片和逐像素编辑。矢量图放大时根据几何描述重绘，通常不会出现像素化；体积取决于对象复杂度，不能一概认定矢量永远更小。

Sound 声音：麦克风得到模拟信号，ADC 定时采样并量化成数字。

  • sampling rate：每秒采样次数，单位 Hz；提高后更好地描述时间上的变化。
  • sampling resolution/bit depth：每个样本的位数；提高后振幅级数增多、量化误差减小。
  • 未压缩声音字节数 = 采样率 × 每样本位数 × 秒数 × 声道数 ÷ 8。
  • 例：44,100 Hz、16-bit、双声道、10 秒 → 1,764,000 B。采样率与位深加倍分别令数据量加倍。

1.3 Compression 压缩

练习本知识点 →

压缩减少存储占用、传输时间与所需带宽，但压缩/解压需要处理时间。

  • Lossless 无损：解压后与原数据一致，适合程序、文字、需要精确保留的图像。可通过重复串的字典替换、重复图形对象引用等去除冗余。
  • Lossy 有损：丢弃部分不易感知的信息，不能完全还原；适合允许质量损失的照片、音频。声音可去除不易听到的频率成分；图像可减少细节或颜色精度。
  • RLE（Run-Length Encoding）：保存连续重复值及次数。例如 AAAABBCCCCC → (4,A)(2,B)(5,C)。适合大片相同颜色的位图，重复很少时反而可能变大；计算必须计入次数和符号各自的存储成本。
  • 文本通常需要无损；矢量图可通过重复对象/属性的编码减少冗余；“压缩”不必然代表降低质量。

自测与易错点

1. 8-bit −42 的补码？答：11010110。解释 BCD 42 为什么是 0100 0010。

2. 1024×768、16-bit 位图的数据大小？答：1,572,864 B = 1.5 MiB（不含文件头）。

3. 能独立完成进制转换、固定宽度加减、溢出判断和图像/音频大小计算；每一步标明 bits 或 bytes。
