15.1 Processors, Parallel Processing and Virtual Machines

练习本知识点 →

RISC 与 CISC

比较RISCCISC
指令集较少、较简单较多、可有复杂操作
指令格式通常较规则/固定长度常有多种长度和格式
内存操作典型 load/store，计算主要在寄存器间某些指令可直接操作内存
寄存器与控制通常强调较多寄存器、规则译码与流水线复杂译码，可能用微码分解复杂操作
完成同一工作可能需更多简单指令可能用较少复杂指令

这些是教学模型中的典型特征，不代表现代处理器严格二分。中断都要保存并恢复上下文；复杂、多周期指令会增加到达安全响应点的时间，寄存器多也增加潜在保存量。不能只背“RISC 的中断永远更快”。

Pipelining 让不同指令重叠处于 fetch/decode/execute 阶段，提高稳定状态的吞吐量，并不缩短每条指令必须经历的全部阶段。假设 k 阶段、每阶段一个周期，理想 n 条指令耗时约 k+n−1 周期，而非 kn；分支、数据依赖和资源竞争会造成停顿或清空流水线。

Flynn 四种架构：SISD 单指令流单数据流；SIMD 同一操作处理多个数据（向量/图像）；MISD 多指令流同数据流，少见；MIMD 多处理器各运行指令处理各自数据。Massively parallel 系统以大量处理单元协作，需要任务可分解、数据分配与通信同步，通信开销与串行部分限制加速。

Virtual machine

System VM 通过 hypervisor 提供虚拟 CPU、内存、磁盘等环境以运行 guest OS；process VM 如 JVM 为程序提供抽象执行环境。两种场景都属于虚拟化，但层次不同。

优点：隔离环境、测试不同 OS、整合服务器、快照和迁移、支持平台抽象。限制：资源开销、主机故障影响多个 guest、硬件支持与性能受限；快照不自动取代独立备份。

15.2 Boolean Algebra and Logic Circuits

练习本知识点 →

用 + 表示 OR、· 表示 AND、¬ 表示 NOT。

  • Identity：A+0=A，A·1=A；domination：A+1=1，A·0=0。
  • Idempotent：A+A=A，A·A=A；complement：A+¬A=1，A·¬A=0。
  • Absorption：A+A·B=A；A·(A+B)=A。
  • De Morgan：¬(A·B)=¬A+¬B；¬(A+B)=¬A·¬B。
  • 化简例：A·B + A·¬B = A·(B+¬B)=A。每一步注明规律，并可用真值表验证。

加法器

Half adder：输入 A、B，Sum=A XOR B，Carry=A AND B。

Full adder：输入 A、B、Cin，Sum=A XOR B XOR Cin，Cout=A·B + A·Cin + B·Cin。

Flip-flops

Flip-flop 保存一位状态 Q，有反馈，属于 sequential logic。题目可能采用 NOR 或 NAND、不同有效电平/时钟配置，先判断符号。

NOR 型 active-high SR latch：S=0,R=0 保持；1,0 置位 Q=1；0,1 复位 Q=0；1,1 为禁止/无效状态。电路为两个交叉反馈 NOR 门，S 驱动产生 ¬Q 的门、R 驱动产生 Q 的门。

JK flip-flop 在有效时钟事件：J=K=0 保持；J=1,K=0 置位；J=0,K=1 复位；J=K=1 翻转 Q。其反馈可理解为受时钟控制的 set=J AND ¬Q、reset=K AND Q；画具体电路时遵循题目时钟/门型。不能把“保持”误写成 Q=0。

Karnaugh map

1. 按 Gray code 00,01,11,10 放行列，邻格仅一变量变化。

2. 为求 sum-of-products，把输出 1 圈成 1、2、4、8……格的矩形，尽量大；可重叠，边界可环绕，不能对角相连。

3. 每组保留不变变量，变化变量消去，各组 OR。

4. 覆盖全部 1、避免覆盖 0，最后回查真值表。

例：三变量中 A=1 的四格全部为 1，圈四格后化简为 Q=A，B、C 被消去。K-map 减少门数量/逻辑复杂度，但有多种等价最简表示。

自测与易错点

1. 理想三阶段流水线执行 10 条指令需 12 周期；解释为何实际可能更多。

2. 用代数和 K-map 分别化简 A·B+A·¬B。

3. 画 SR/JK 电路时明确时钟和有效电平，再列状态表。
