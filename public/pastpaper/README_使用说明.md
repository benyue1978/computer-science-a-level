# Cambridge 9618 自习室：使用说明

这是一套可整体复制的静态学习网站，面向 Cambridge International AS & A Level Computer Science（9618）。当前界面围绕“按考纲章节学习、筛题、打印”组织，不要求学生在网页里作答或登录。

## 学生使用流程

1. 打开 `index.html`，选择 P1、P2、P3 或 P4，再选择一个考纲主题。
2. 页面先显示该主题的笔记，包括中文说明、英文术语与双语记忆卡、步骤、易错点和题型方法卡。
3. 在同一主题下按练习方式、难度或关键词筛选题目。结果按估计难度从低到高排列；展开题目可看英文原题、中文讲解、解题步骤、易错点和官方评分依据。
4. 点击“打印本章笔记”可生成独立笔记打印页。题目可逐题勾选，也可打印全部筛选结果；打印页支持“题目与讲解合并”“只打印题目”“只打印答案讲解”或“题目册 + 独立答案册”。

题目展开后，原卷题目裁图放在题目区最前面，保留代码缩进、表格和图示；抽取文字用于搜索和阅读，格式以原卷图版为准。官方评分标准原页单独列在答案区。可能包含相邻小问的整页原卷默认收起，需要时再展开；若图片资源确实缺失，页面会显示文件名和对应 PDF 入口。

打印页里点“打开打印对话框”，再用浏览器的打印或“另存为 PDF”。题目册和答案册使用相同的顺序编号，方便配对。浏览器若拦截新页面，请允许此站点打开弹出页面。

## 页面与资料

- `index.html`：章节笔记、历年题目筛选及打印入口。
- `print.html`：打印预览与打印格式选择。
- `coverage.html`：逐卷收录范围、文件缺档与数据边界。
- `start.html`：原有的入门说明页。
- `lessons/`：按主题整理的独立 HTML 笔记页。

将整个 `9618_study_site/` 文件夹一起复制，保留 `assets/`、`data/`、`lessons/`、`media/`、`sources/` 的相对位置。没有外部 CDN 或构建步骤。建议通过静态网站托管或本地静态文件服务器打开，确保新打印页可读取当前选择的数据。整包约 0.74 GiB，主要由原题/评分页图像与 PDF 构成；部署前检查托管空间限额。

文件包含 Cambridge 原题、评分标准及其页面图像。公开托管前，请先确认你的使用场景符合相应资料的授权与使用条件。

## 数据结构与收录边界

- `data/p1.json` 至 `data/p4.json`：逐题数组；每项保留稳定题目 ID、原卷 ID、题号、考纲标签、题目与评分文本、QP/MS 来源、英文页图、分值、难度、练习方式、中文说明/解题步骤/失分点和来源核对提示。对应 `.js` 文件挂到浏览器的 `window.BANK1` 至 `window.BANK4`。
- `data/catalog.json`：试卷目录、主题目录与总体统计；`data/guides.json`：按主题组织的解释、双语记忆卡、步骤和方法卡；`data/coverage.json`：逐卷题项、分值、定位及未匹配/缺档清单。对应 `.js` 文件供本地 HTML 直接加载。
- `media/` 保存按题号命名的原卷页面图片；`sources/` 保存随卷 PDF、可用的支持 ZIP 和考纲文件。题库同时提供原始 PDF 来源链接，便于回到上下文。

当前整理的是工作目录里找到的 118 份试卷：P1 30 份、P2 30 份、P3 29 份、P4 29 份；这不表示每个历史考季都齐全。覆盖账本逐题列出本地收录范围和缺失支持文件，不会用猜测补造输入数据或输出。

难度 1–4 表示学习步骤和状态追踪的估计负担，不是 Cambridge 官方等级，也不是考生实际得分率。练习方式是学习分类，不代表考试官方题型。每道题保留英文原文与官方评分依据，中文内容用于自学辅助。
